# rogerpanel/cv

Research repository of Dr Aminat Abiola Ajibola: dissertation sources, paper manuscripts (LaTeX),
notebooks, and project codebases.

## Active project: ML for mental-health prediction (paired systematic appraisal + empirical study)

**[`mlmh-appraisal/`](mlmh-appraisal/)** is the codebase and living record for the paired-paper
project:

* **Paper A** a systematic review and PROBAST+AI / TRIPOD+AI critical appraisal of machine-learning
  models for mental-health prediction (protocol, PROSPERO text and extraction workbook in
  `mlmh-appraisal/paper/review/`);
* **Paper B** an empirical companion that quantifies, on public actigraphy cohorts, the cost of
  leaky splitting (E1), of skipping external validation (E2) and of ignoring calibration (E3).

Start with [`mlmh-appraisal/README.md`](mlmh-appraisal/README.md) (status, quickstart, current
results, roadmap), then [`mlmh-appraisal/docs/venue_analysis.md`](mlmh-appraisal/docs/venue_analysis.md),
[`mlmh-appraisal/docs/gap_review.md`](mlmh-appraisal/docs/gap_review.md) and
[`mlmh-appraisal/data/README.md`](mlmh-appraisal/data/README.md) (how to obtain each dataset). The
full analysis document is `mlmh-appraisal/paper/analysis/P1_analysis_venue_gaps.tex`.
