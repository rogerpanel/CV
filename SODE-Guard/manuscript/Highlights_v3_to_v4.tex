\section{Block-level additions}
%% ============================================================================
Highlight the entire block in each case.
\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Abstract.} Added the sentence starting ``The chaos truncation degree is now selected adaptively per example \ldots'' and the last sentence describing problem-space projection.
  \item \textbf{\S1 (Introduction).} Added the ``What is genuinely new in the composition'' paragraph after C0.
  \item \textbf{\S3.2 (BEL identity).} Added Equation~(2) defining $g^{+}$ and re-stated Theorem~2 with the pseudo-inverse.
  \item \textbf{\S3.3 (Carbery--Wright).} Added the sentence ``The denominator is the exact $L^2$ norm of $p$. The revised Proposition~5 uses a Hoeffding lower confidence bound \ldots''.
  \item \textbf{\S3.4 (PAC-Bayes).} Added the reference to Reeb--Seldin kl-inversion.
  \item \textbf{\S4 (Framework).} Added Assumption~1 (analytic $\leftrightarrow$ implementation).
  \item \textbf{\S4.1 (Flow representation).} Added the italicised note ``The SDE evolves the embedded state $X_t$ \ldots''.
  \item \textbf{\S4.3 (Training procedure).} Added Equation~(7) with the explicit $\mathcal L_{\mathrm{AC}}$ formula.
  \item \textbf{\S4.} Added Algorithm~2 (adaptive chaos-degree estimator).
  \item \textbf{\S5 (Theory).} Added Definition~4 (three robustness quantities), Lemma~3 (closed-form $L_g$), Corollary~1 (decision-flip bound), Remark~8 (why differs from randomised smoothing), Remark~9 (why $L_{\mathrm{lo}}$ not $L_g$).
  \item \textbf{\S6.1 (Datasets).} Added the ``Provenance, deduplication, leakage'' paragraph.
  \item \textbf{\S6.2 (Baselines).} Split into ``threat-model-matched neural'' and ``reference'' groups.
  \item \textbf{\S6.4 (Ablation).} Added the row ``$-$ Adaptive $d^\star_{p99}$ (fix $d^\star=4$)''.
  \item \textbf{\S6.5.1 ($\sigma$ sweep).} New Table~6.
  \item \textbf{\S6.6 (Split-Protocol Audit).} New \S6.6, new Tables~7 and~8, new Table~9.
  \item \textbf{\S6.7 (Reference baselines).} Moved commercial + LLM-policy comparison into its own subsection with Table~10.
  \item \textbf{\S6.8 (Diagnostics).} New subsection with Tables~11 (certified $L_g$), 12 (PAC-Bayes + ECE), 13 (BEL bias / variance).
  \item \textbf{Appendices A--F.} All new.
\end{itemize}
