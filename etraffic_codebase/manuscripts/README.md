## Paper Highlights

1. Hybrid CNN-BiLSTM-Transformer-GNN achieves 97.8--99.9% encrypted traffic detection.
2. Protocol-aware certified robustness enlarges robust radii by 58% over standard methods.
3. Byzantine-resilient federated learning maintains >95% accuracy under 40% adversaries.
4. Self-supervised pretraining improves few-shot zero-day detection by 7.3 percentage points.
5. Six-month pilot deployment validates 0.18% false positive rate on 10,000 devices.
