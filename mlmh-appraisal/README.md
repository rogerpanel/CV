# Machine learning for mental-health prediction: a systematic appraisal and an empirical demonstration

**Status: pre-registration / scaffolding.** Codebase verified end to end on a synthetic fixture;
waiting for the real cohorts to be placed in `data/raw/` (see [`data/README.md`](data/README.md)).
This README is the living record of the project: the results section below is regenerated by
`scripts/update_readme.py` every time an experiment is re-run, and the manuscript tables in
`paper/empirical/tables/` are written by the code, never by hand.

Principal investigator: Dr Aminat Abiola Ajibola. Companion documents: `docs/venue_analysis.md`,
`docs/gap_review.md`, `paper/analysis/P1_analysis_venue_gaps.tex` (the full analysis of the
proposal), `paper/review/` (Paper A protocol, PROSPERO text, extraction workbook),
`paper/empirical/` (Paper B manuscript skeleton with auto-generated tables).

## The argument

* **Paper A (systematic review + critical appraisal).** How methodologically sound and completely
  reported are ML models for mental-health prediction? PROBAST(+AI) and TRIPOD+AI applied across
  all populations, disorders and modalities, 2018-2026. Primary outcomes: external validation,
  calibration, AUROC vs accuracy, leakage-prone evaluation design, EPV, code/data availability.
* **Paper B (empirical companion, this codebase).** Takes public actigraphy cohorts and quantifies
  the cost of three of those failures on real data:
  * **E1** the cost of leaky splitting: the same model under record-wise vs subject-wise CV;
  * **E2** the cost of skipping external validation: train on one cohort, evaluate unchanged on another;
  * **E3** the calibration blind spot: slope, intercept, Brier, ECE and reliability curves for every model.

Neither paper is remarkable alone; together they measure how widespread the problem is *and* how
much it costs. See `docs/venue_analysis.md` for where each paper should go and how every review
outcome maps to an experiment, a module and a test.

## Cohorts

| Cohort | Content | Access | Role |
|---|---|---|---|
| DEPRESJON | actigraphy, 23 depressed (uni/bipolar) + 32 controls, MADRS | open, cite | E1, E2 (train/test) |
| PSYKOSE | actigraphy, 22 schizophrenia + **the same 32 controls** | open, cite | E1, E2 |
| HYPERAKTIV | actigraphy, 51 ADHD + 52 clinical controls (activity for 85) | open, cite | E1, E2 label-shift test |
| OBF-Psychiatric | the three above harmonised, 162 participants / 1,565 days (Sci Data 2025) | open, Zenodo | canonical source, multiclass |
| DAIC-WOZ / E-DAIC | clinical interviews, PHQ-8 | EULA | secondary (benchmark validity is contested; see `docs/gap_review.md`) |

Datasets are never pooled into one training corpus. They are separate cohorts: train on one,
validate unchanged on another. The DEPRESJON/PSYKOSE shared control group is detected from the
activity series themselves and resolved before any cross-cohort run.

## Non-negotiable engineering rules (each enforced by a test)

1. **Subject-wise splitting is the default everywhere.** `RecordWiseSplit` is used only inside E1,
   where the inflation it causes is the object of study. `tests/test_no_subject_leakage.py` fails
   the build if any non-E1 config requests it, and the CV runner asserts fold disjointness at run time.
2. **All preprocessing lives inside the `imblearn` Pipeline.** Imputation, scaling and SMOTE are
   fitted on training folds only. `tests/test_pipeline_fit_order.py` guards it and greps the source
   for `fit_transform` outside a Pipeline.
3. **Bootstrap at the subject level** (BCa, jackknife over subjects), never at the window level.
4. **Cross-cohort runs refuse to start if a participant is on both sides**, by identifier or by
   activity-series hash.
5. **Every run writes a manifest**: git SHA, dirty flag, config hash, seeds, package versions,
   dataset checksums, synthetic flag. A table without a manifest does not go in the paper.
6. **Seeds fixed and recorded**; default 10 seeds.
7. **Raw data never enters git.**

## Quickstart

```bash
cd mlmh-appraisal
pip install -e .[dev]          # add [cnn] for the 1D-CNN (PyTorch)
python -m pytest               # 26 tests; the leakage test must pass before anything else is trusted

# Without real data: exercise everything on the synthetic fixture
python -m mlmh synth && python -m mlmh prepare --synthetic
python -m mlmh run configs/e1_split_leakage.yaml --synthetic --seeds 0 1 2 --n-boot 200
python -m mlmh run configs/e2_external_val.yaml --synthetic --seeds 0 1 2 --n-boot 200
python -m mlmh run configs/e3_calibration.yaml --synthetic
python -m mlmh tripod --synthetic && python scripts/update_readme.py --synthetic

# With real data in data/raw/ (see data/README.md)
python -m mlmh verify-data && python -m mlmh prepare
python -m mlmh run configs/e1_split_leakage.yaml
python -m mlmh run configs/e2_external_val.yaml
python -m mlmh run configs/e3_calibration.yaml
python -m mlmh tripod && python scripts/update_readme.py
```

Outputs: `results/<real|synthetic>/E*/` (CSV summaries, per-window predictions, manifest),
`paper/empirical/tables/*.tex`, `paper/empirical/figures/*.pdf`,
`results/<real|synthetic>/tripod_ai_self_audit.md`.

## Metrics and estimands

* Discrimination: AUROC (primary), AUPRC, accuracy, balanced accuracy, macro-F1, MCC.
* Calibration: Brier score, calibration slope and intercept (Van Calster et al. 2019), ECE,
  reliability curves.
* Two levels: **window-level** (one calendar day of activity; the unit most papers report) and
  **subject-level** (mean predicted probability per participant; the clinically meaningful unit).
* Uncertainty: mean and SD over seeds; subject-level BCa 95 % bootstrap intervals on the
  seed-averaged out-of-fold predictions; E1 inflation as a *paired* subject-bootstrap difference.
* Note: the majority-class baseline's pooled AUROC deviates slightly from 0.5 because its constant
  prediction differs across folds; it is reported as a sanity check, not a comparator.
