\textbf{Highlights.}
\begin{itemize}[nosep,leftmargin=1.4em]
\item Leakage-safe evaluation protocol for repeated-measures wearable data, released as tested code
\item Day-level cross-validation inflated AUROC by up to 0.17 and scored 0.69 to 0.90 on random labels
\item One day of activity re-identifies a participant with 27 to 40\% top-1 accuracy (chance 1 to 2\%)
\item Frozen cross-cohort transfer lost up to 0.21 AUROC with collapse of calibration
\item Every published claim above the honest band used or did not state a day-level unit
\end{itemize}
