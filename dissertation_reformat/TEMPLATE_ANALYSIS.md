## 2. Каноническая структура Введения (Russian VAK)

(совпадает во всех трёх шаблонах, в указанном порядке)

1. **Актуальность темы исследования** — мотивация, общественная и
   технологическая значимость; не более 3–4 страниц.
2. **Степень разработанности проблемы** — обзор отечественных и
   зарубежных коллективов и направлений с конкретными именами и
   ссылками.
3. **Объект исследования** — одна фраза.
4. **Предмет исследования** — одна фраза.
5. **Цель диссертационной работы** — одна целевая формулировка.
6. **Задачи исследования** — нумерованный список из 5–8 пунктов.
7. **Методология и методы исследования** — короткий перечень формальных
   аппаратов (теория графов, оптимальный транспорт, дифференциальная
   приватность и т.д.).
8. **Научная новизна** — нумерованный список из 4–6 пунктов
   («впервые …»).
9. **Теоретическая значимость** — 1–2 абзаца.
10. **Практическая значимость** — 1–2 абзаца, с указанием конкретных
    внедрений (RobustIDPS.ai, акты внедрения).
11. **Положения, выносимые на защиту** — нумерованный список из 4–7
    пунктов, дублирующих научную новизну с акцентом на доказательность.
12. **Достоверность полученных результатов** — обоснование (теоремы,
    эксперименты, сопоставление с опубликованными работами, объём
    экспериментальной выборки).
13. **Апробация результатов исследования** — конференции, семинары,
    обсуждения на кафедре.
14. **Публикации** — числовое распределение: <X> работ, в т.ч. <Y>
    в журналах ВАК / <Z> Scopus / WoS / <W> патентов / свидетельств о
    регистрации ПО.
15. **Личный вклад автора** — формальное заявление.
16. **Структура и объем работы** — число страниц, число рисунков, число
    таблиц, число использованных источников.
17. **Соответствие специальности** (присутствует у Григорьева и
    Абидовой) — обоснование принадлежности к паспорту 2.3.1 по
    конкретным пунктам.

(общий шаблон, выводимый из всех трёх работ)

```
СОДЕРЖАНИЕ

ВВЕДЕНИЕ                         ← пп. 1–17 раздела 2 выше

Глава 1. Современное состояние исследований / Анализ предметной области
   1.1. <обзор подобласти 1>
   1.2. <обзор подобласти 2>
   ...
   1.N. Постановка задачи диссертационного исследования
   1.N+1. Выводы по главе 1                  ← ОБЯЗАТЕЛЬНО

Глава 2. Теоретические основы / Модели и методы
   2.1. <теоретический аппарат>
   ...
   2.N. Выводы по главе 2

Глава 3. Алгоритмы / Проектирование
   3.1. <алгоритм 1>
   ...
   3.N. Выводы по главе 3

Глава 4. Экспериментальное исследование и апробация
   4.1. <условия экспериментов / датасеты>
   4.2. <результаты по методам>
   4.3. <внедрение / интеграция>
   4.N. Выводы по главе 4

(Глава 5 — только для докторских работ.)

ЗАКЛЮЧЕНИЕ                       ← нумерованный список 5–10 результатов
СПИСОК СОКРАЩЕНИЙ                ← если не вынесен в начало
СПИСОК ЛИТЕРАТУРЫ                ← ГОСТ Р 7.0.5-2008
ПРИЛОЖЕНИЕ А. <Акт внедрения 1>
ПРИЛОЖЕНИЕ Б. <Акт внедрения 2>
ПРИЛОЖЕНИЕ В. <Патенты / свидетельства о регистрации ПО>
```

Каждая глава должна заканчиваться разделом **«Выводы по главе N»** в
формате нумерованного списка из 3–7 пунктов (присутствует и в работе
Романова, и в работе Абидовой).

## 4. План преобразования текущей работы

### 4.1. Картирование текущих английских глав в новую структуру

Текущая работа имеет 10 английских глав (chapters/chapter1-10). Шаблон
ВАК 2.3.1 требует 4–5 глав. Предлагается следующее объединение:

| Текущая (англ.) | Новая (рус.) | Комментарий |
|---|---|---|
| Ch.~1 Introduction | переходит в Введение (VAK skeleton) | заменяется полностью |
| Ch.~2 Problem Formulation | Глава 1 §1.N | постановка задачи |
| Ch.~3 Literature Review | Глава 1 §1.1–§1.M | анализ предметной области |
| Ch.~4 Neural ODE (\textsf{M1}) | Глава 2 §2.1 | теоретическая глава |
| Ch.~5 Optimal Transport (\textsf{M2}) | Глава 2 §2.2 | теоретическая глава |
| Ch.~6 Encrypted Traffic | Глава 2 §2.3 | теоретическая глава |
| Ch.~7 Federated Learning (\textsf{M2,M7}) | Глава 3 §3.1 | алгоритмы |
| Ch.~8 Graph Methods (\textsf{M3,M4}) | Глава 3 §3.2–§3.3 | алгоритмы |
| Ch.~9 Experiments | Глава 4 §4.1–§4.M | эксперимент |
| Ch.~10 Conclusions | переходит в Заключение | заменяется полностью |
| `chapter6_uav_defense.tex` (новая, рус.) | Глава 5 (UAV) | для докторской структуры |

Альтернатива «слияние ради компактности»: упаковать M1–M7 в две главы
вместо трёх (Глава 2 теория + Глава 3 алгоритмы и эксперимент).
Окончательное решение — за автором.

```
└── chapters_ru/
    ├── titlepage_ru.tex             ← русский титул по шаблону НИЯУ МИФИ
    ├── abbreviations_ru.tex         ← Список условных сокращений
    ├── introduction_ru.tex          ← Введение со всеми 17 секциями
    ├── chapter1_state_of_art.tex
    ├── chapter2_theory.tex
    ├── chapter3_algorithms.tex
    ├── chapter4_experiments.tex
    ├── chapter5_uav_defense.tex     ← перенос текущей UAV-главы
    ├── conclusion_ru.tex

```

Существующие английские chapters/ сохраняются нетронутыми — на случай,
если нужна параллельная сборка англоязычной версии для публикации
журнальных статей.

### 4.3. Новая тема диссертации

```
Состязательно-устойчивые модели и алгоритмы повышения
робастности и эффективности гибридных систем обнаружения
и предотвращения вторжений в распределённых и нестационарных
условиях
```

будет внесена в:
- `dissertation_reformat/chapters_ru/titlepage_ru.tex`
- `dissertation_reformat/Dissertation_RU.tex` (\title{...})
- `chapters/titlepage.tex` (если требуется английский вариант)
- `PhD_Thesis_Integrated.tex` (\title{...} и \hypersetup{pdftitle=...})

### 4.4. Порядок исполнения

Согласно указанию автора («one after another»):

1. **(сделано)** Глава 6 UAV-защиты на русском — добавлена в
   `chapters/chapter6_uav_defense.tex`. Ожидается верификация
   компиляции на Overleaf.
2. **(следующий шаг, по подтверждению)** Изменение названия:
   `titlepage.tex`, `\title{}` и `\hypersetup{pdftitle=…}` в основном
   драйвере.
3. **(следующий шаг)** Создание скелета русскоязычной версии
   `dissertation_reformat/` с титульным листом и Введением по ВАК-форме.
4. **(пошагово)** Преобразование глав 1–4 английского текста в
   русскоязычные главы 1–4 по шаблону.
5. **(финал)** Заключение, Список сокращений, Список литературы по
   ГОСТ Р 7.0.5-2008, Приложения с актами внедрения.

Каждый шаг будет согласовываться с автором перед фиксацией на ветке.
